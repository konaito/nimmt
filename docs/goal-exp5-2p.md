# exp5/exp6: 2人戦モデルの強化（2026-08-27 事前登録）

exp2（2人戦・絶対報酬）を置き換える強い2人戦モデルを作る。
根拠: 4人戦で実証済みの2レバー（相対報酬 exp3>exp1、温め直し exp4>exp3）が2人戦に未適用。

## 実験

- **exp5** = 2人戦・相対報酬・3000イテレーション・新規（他ハイパラはexp2と同一、seed=0）
- **exp6** = exp5 の `--init-from` 温め直し3000（ent 0.002固定、seed=1）— exp4と同じ処方

## 受け入れゲート（新2人戦モデルとして採用する条件）

1. `ablation.py --players 2`（2万ディール、[A,B]交互着席）で **exp2に有意勝ち**（差<0、95%CIが0を跨がない）
2. `report.py` の2人戦で heuristic と mc-rollout(n=24) 両方に有意勝ち（exp2は両方通過済みなので、退行しないこと）

exp6がexp5に有意勝ちならexp6、そうでなければexp5とexp6の強い方をゲートにかける。
ゲートを通ったモデルで Pages の weights_exp2 相当を差し替える（ゴールデン照合を再生成して61ケース相当の全一致を確認してから）。
どの結果でも数字は公開する。
