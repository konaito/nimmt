# exp4: 最強モデル作成の受け入れ条件（2026-08-25）

「最強」は **4人戦（本命ゲーム）** で定義する。2人戦は exp2 のままとする。

## 受け入れゲート（すべて必須）

新モデル（exp4）の `latest.pt`（またはElo最良チェックポイント）が:

1. `report.py`（4人戦2万ディール・EVAL_SEED=20260831）で heuristic **と** mc-rollout(n_samples=24)
   の両方に対し、平均失点差が負かつ95%CIが0を跨がない
2. `ablation.py`（2万ディール・EVAL_SEED=20260901）で **exp3** と直接対戦して差が負・CIが0を跨がない
3. 同じく **exp1** と直接対戦して差が負・CIが0を跨がない

注: mc-rollout ゲートは形式的でない。exp3系統（相対報酬）は mc-rollout とのフル対戦を
まだ一度も通っておらず、通っているのは exp1 のみ。

## 実験設計（1変数比較）

- exp4 = exp3 の続き学習。`--init-from` で exp3 のElo最良チェックポイントから温め直し
- ハイパラは exp3 と同一。ただしエントロピー係数のみ、exp3 のスケジュール終端値
  （ent_end=0.002）でフラット継続（ent-start=ent-end=0.002）。
  収束済み方策に ent_start=0.02 を再適用すると意図的に方策を鈍らせることになるため
- これにより exp4 vs exp3 は「追加学習の有無」だけの1変数比較になる

## 判定手順

1. exp3 のチェックポイントEloをローカルで測り、warm-start のシードを選ぶ
2. exp4 をリモート（M4）で3000イテレーション学習
3. 並行してローカル（M5）で exp3 のフル `report.py` を回し、現チャンピオンを確定
4. exp4 完走後、ゲート1〜3を判定。通れば `docs/results.md` を更新して完了
5. 通らなければ「現容量では頭打ち」の証拠とみなし、ネット容量を1段階上げて（hidden 384）
   新規学習にエスカレーション
